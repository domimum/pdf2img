PDF 拆页助手（Windows 版）— 使用说明
========================================

【这是什么】
一个单文件网页工具，双击即可用，不用安装任何软件、不用联网。
基于浏览器运行，Windows 上用 Edge 或 Chrome 打开即可（推荐 Edge）。

【怎么打开】
双击「PDF拆页助手.html」——会自动用默认浏览器打开。
如果双击没反应，右键 -> 打开方式 -> 选 Microsoft Edge 或 Chrome。

【怎么用 —— 先勾选，再存图】
1. 点「打开 PDF」选择文件，或直接把 PDF 拖进窗口。
2. 每页缩略图铺开显示。
3. 单击页面 = 选中（蓝色边框+蓝色序号），再单击 = 取消。
4. 双击页面 = 弹出大图高清查看（按 ESC 或点图片关闭）。
5. 选好后点右上角「存选中 (N)」→ 只保存选中的页，没选的不处理。
6. 右上角「清空选择」可取消全部勾选。

【保存到哪里】
- 点「📁 保存位置」选一次文件夹（比如桌面），之后图片直接存进去并记住。
- 如果浏览器不支持选文件夹，图片会存到浏览器的「下载」文件夹。
- 图片格式文件名：原文件名_第N页.png，同名自动加 _2、_3。
- PDF 格式文件名：原文件名_选中N页.pdf（所有选中页合并成一个矢量 PDF）。
- 存完弹出「已存完 ✓」窗口，列出保存的文件名。

【顶部选项】
- 清晰度：普通150 / 高清300 / 打印450 DPI（选 PDF 时自动禁用，矢量无损）。
- 格式：
  · PNG —— 清晰无损
  · JPG —— 体积小
  · PDF —— 把选中页合并成一个矢量 PDF，无损、可缩放，适合打印或再编辑

【小提示】
- 首次打开会稍等 1~2 秒加载内嵌的 PDF 引擎，属正常。
- 建议用 Edge / Chrome，功能最完整。
- 不联网也能用，PDF 文件不会上传到任何地方，安全。
