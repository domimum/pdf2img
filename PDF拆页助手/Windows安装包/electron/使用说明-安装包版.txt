PDF 拆页助手 - Windows 桌面软件版 使用说明
============================================

【这是什么】
一个 Windows 桌面软件（免安装绿色版），和 Mac 上的 App 一样是独立程序，
不需要联网、不需要浏览器、不需要网址，双击 exe 就能用。

【怎么运行】
1. 把整个「PDF拆页助手-Windows安装包」文件夹拷贝到电脑任意位置
   （建议放在 D 盘或桌面，不要放在需要管理员权限的目录）。
2. 双击文件夹里的「PDF拆页助手.exe」打开。
3. 首次运行如果 Windows 弹出"Windows 已保护你的电脑"提示，
   点「更多信息」→「仍要运行」即可（因为软件没买数字签名）。

【怎么用】
1. 点「打开 PDF」或「打开 PDF 文件」，在弹出的窗口里选你的 PDF。
2. 缩略图加载出来后：
   - 单击页面 = 勾选/取消勾选（可多选）
   - 双击页面 = 放大查看大图
3. 右上角「保存位置」：选一个文件夹；不选的话默认存到 PDF 所在文件夹。
4. 选好「格式」（PNG / JPG / PDF）和「清晰度」。
5. 点右上角「存选中 (N)」，会弹出"已存完"窗口并列出保存的文件名。
   - 没选中的页一律不会保存。

【格式说明】
- PNG：图片，清晰无损
- JPG：图片，文件更小
- PDF：把你选中的页原样合并成一个新的矢量 PDF（推荐，无损）

【常见问题】
Q：打开后缩略图一直转圈？
A：页数很多（如上百页）时需要一点时间生成，界面会显示"生成缩略图 X/N"进度。
   如果个别页失败会显示 ⚠️，点该页可单独重试，不影响保存。

Q：杀毒软件报毒？
A：这是 Electron 打包的通用现象，误报。选择信任/允许即可。

Q：能换保存位置吗？
A：能，点右上角「📁 保存位置」重新选文件夹。

【文件构成】
- PDF拆页助手.exe  主程序，双击运行
- 其余 dll / pak / bin 等  程序运行必需文件，请勿删除或单独移动
- 整个文件夹要一起拷贝，不能只拷 exe
